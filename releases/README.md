# Release manifests

Every production deployment gets one immutable JSON manifest generated by
`scripts/build_release_manifest.py`.

The manifest records release version, Git SHA, Flutter version, Alembic migration
head, REST/realtime/GraphQL/game/asset contract versions, feature-flag snapshot,
all 17 immutable backend image digests and rollback target.

Do not hand-edit a generated manifest after promotion. If deployment inputs
change, generate a new release version/manifest.
