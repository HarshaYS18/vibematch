# Security policy

Report security vulnerabilities privately through the repository security
advisory channel. Do not open a public issue containing exploit details,
credentials, private user data or unredacted production logs.

FunKey treats authentication, Economy/ledger integrity, private-room access,
moderation controls, media authorization and supply-chain compromise as
high-priority security boundaries.

Production secrets must come from approved secret management/workload identity.
Never commit tokens, private keys, cloud credentials, provider service-account
files or real user datasets.
