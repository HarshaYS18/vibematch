# RFC process

Use an RFC for changes spanning multiple owners or requiring staged rollout.

An RFC records problem, constraints, alternatives, decision, authority impact,
contracts, security/privacy impact, capacity assumptions, migration/rollback,
SLO/observability, test plan and decommission date for transitional paths.

ADRs capture a durable decision. RFCs capture the design/review process leading
to a large change. Both evolve with code and must link to implementation PRs.
